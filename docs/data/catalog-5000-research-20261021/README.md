# Research artifacts for the 5,000-place plan

These are research decisions and measurements, **not accepted attraction rows**.
See [the full plan](../../catalog-5000-plan-20261021.md). The prior 93-place
implementation remains separate in `../catalog-expansion-20261021/`.

| File                                 | Purpose                                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| `root-source-portfolio.json`         | Wikidata, Hugging Face, Overture, OSM, AllThePlaces, Kaggle, IMLS and earlier USFS decisions |
| `culture-source-portfolio.json`      | Eleven heritage, museum, public-art and garden source assessments                            |
| `nature-food-source-portfolio.json`  | Twelve recreation, wildlife, state-park, science and food source assessments                 |
| `niche-reddit-source-portfolio.json` | Eleven niche-directory decisions, rights and conditional opportunities                       |
| `reddit-leads.json`                  | Four discussion links and ten operator traces, with unknown arrivals and admission status    |
| `research-receipts.json`             | 256 direct request receipts, including errors; 249 saved original-response hashes            |
| `coverage-and-sizing.json`           | Reproducible 603/696 local coverage and actual 93-record artifact sizes                      |
| `derived-metrics.json`               | Measured NPS/SF source grouping diagnostics                                                  |
| `nhl-listed-leads-by-state.json`     | Native NPS identifiers for investigation, not proof of public access                         |
| `program.json`                       | Conditional work objectives, sensitivity arithmetic, pilot denominator and permissions       |
| `validation.json`                    | Local artifact checks and independent review scope                                           |
| `artifact-manifest.json`             | File sizes and SHA256 hashes, excluding the manifest itself                                  |

All conditional source ranges are unmeasured planning assumptions. Sources overlap;
never sum their ranges or raw row counts. The 14,100-prospect queue is a proposed
work requirement and has not been assembled. The 5,600 objective is not an observed
yield. Newly admitted places in this research: **zero**. Live net additions remain
unknown until a complete current catalog snapshot is available.

Original responses are retained under
`/workspace/catalog-plan-5000-20261021/`, grouped as `root`, `culture`,
`nature-food`, and `niche-reddit`. Receipt paths resolve within their `probe_group`.
Recompute SHA256 over original bytes to check retention integrity. This proves
byte consistency, not source truth, operating status or redistribution rights.
Copyrighted pages are not bundled here; source links and short factual summaries
are supplied for review. No public artifact URL or external upload was created.
